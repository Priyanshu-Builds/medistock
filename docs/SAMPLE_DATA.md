## 9. Testing Workflow

Follow this sequence to test all features:

### Day 1 - Setup
1. ✅ Add all categories
2. ✅ Add all warehouses
3. ✅ Add all suppliers
4. ✅ Add all products (with images if testing upload feature)
5. ✅ Set initial inventory quantities

### Day 2 - Purchase Orders
1. ✅ Create Purchase Order 1 (status: pending)
2. ✅ Approve PO 1 (status: approved)
3. ✅ Receive PO 1 items (updates inventory)
4. ✅ Create Purchase Order 2
5. ✅ Create Purchase Order 3

### Day 3 - Sales Orders
1. ✅ Create Sales Order 1 (status: pending)
2. ✅ Start processing SO 1
3. ✅ Mark SO 1 as shipped (deducts inventory)
4. ✅ Mark SO 1 as delivered
5. ✅ Generate invoice for SO 1 (test PDF)
6. ✅ Create Sales Orders 2 & 3

### Day 4 - Stock Transfers
1. ✅ Create Transfer 1 (pending)
2. ✅ Mark Transfer 1 as in-transit
3. ✅ Complete Transfer 1 (updates both warehouses)
4. ✅ Create Transfer 2

### Day 5 - Reports & Features
1. ✅ View Inventory Valuation report
2. ✅ Check Low Stock Alerts
3. ✅ Review Stock Movement analysis
4. ✅ Generate Sales Analytics
5. ✅ Generate Purchase Analytics
6. ✅ View product detail page (with barcode/QR)
7. ✅ Download barcode/QR code
8. ✅ Test Settings (profile, password, user management)

## Tips for Testing

1. **Start Fresh**: Use a clean Supabase project or reset tables
2. **Follow Order**: Add data in the order listed (categories → warehouses → suppliers → products → inventory)
3. **Test Workflows**: Follow the Day 1-5 testing sequence
4. **Check Permissions**: Test with different user roles
5. **Verify Calculations**: Check that totals, inventory adjustments, and stock movements are accurate
6. **Test Features**: Don't forget to test image upload, barcode generation, and PDF invoices
7. **Monitor Reports**: Ensure analytics update correctly after transactions
